# سمارٹ روزنامچہ: "رجسٹر اسٹائل" ڈیزائن اپ گریڈ

آپ کی ہدایت کے مطابق روزنامچہ (Diary) کے ریکارڈز کو اب ایک مکمل ڈاکومنٹ اور رجسٹر کی شکل دے دی گئی ہے، جو پڑھنے اور استعمال کرنے میں انتہائی آسان ہے۔

## نئی تبدیلیاں اور بہتری

### 1. تحریر کے لیے پوری جگہ (Full Width Narrative)
- اب تحریر کے ساتھ بٹنز نہیں ہوں گے، بلکہ تحریر کو **پوری لائن** ملے گی۔
- اگر تحریر 2 یا 3 لائنوں کی بھی ہو، تو وہ رجسٹر کے صفحے کی طرح واضح نظر آئے گی۔

### 2. بڑے اور واضح فونٹس (Large Fonts)
- تحریر کے سائز کو بڑا کر دیا گیا ہے (**18px**) تاکہ دور سے بھی آسانی سے پڑھی جا سکے۔
- رقم (Numbers) کو مزید بڑا اور نمایاں (**22px**) کیا گیا ہے تاکہ حساب فوراً نظر آ جائے۔

### 3. بٹنز کی نئی ترتیب (Action Buttons Relocation)
- **ایڈیٹ اور ڈیلیٹ** کے بٹنز اب تحریر کے نیچے ایک الگ لائن میں منتقل کر دیے گئے ہیں۔
- اس سے ڈیزائن مزید صاف ستھرا (Clean) ہو گیا ہے اور تحریر پڑھتے وقت بٹنز رکاوٹ نہیں بنتے۔

### 4. جدید کارڈ ڈیزائن
- ہر انٹری اب ایک خوبصورت سفید کارڈ میں ہے جس کے اوپر تاریخ اور کیلنڈر کا آئی کن موجود ہے۔
- کارڈ کے گرد ہلکا سا سایہ (Shadow) اسے اسکرین پر نمایاں کرتا ہے۔

## ٹیکنالوجی کی تفصیل
- **Layout:** Switched from `Row` to `Column` structure in entry rows.
- **Typography:** Increased font sizes and line height for better readability.
- **UI:** Implemented full-width text blocks for narrative consistency.

> [!TIP]
> اب آپ لمبی تفصیلات بھی بول کر درج کر سکتے ہیں، وہ پوری اسکرین پر واضح نظر آئیں گی۔

> [!IMPORTANT]
> ہر انٹری کے نیچے دائیں جانب موجود پنسل اور کچرے کے ڈبے کے بٹن سے آپ ترمیم یا خاتمہ کر سکتے ہیں۔
