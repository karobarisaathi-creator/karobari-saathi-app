# دوہری شناخت کے نظام (Personal vs Seller) کا واک تھرو

اس اپ ڈیٹ میں ہم نے ایک ہی ایپ کے اندر "ذاتی پروفائل" اور "کاروباری اسٹور" کو الگ الگ کر دیا ہے تاکہ آپ کی دکان کی پہچان آپ کے ذاتی کھاتوں سے مختلف رہ سکے۔

## اہم تبدیلیاں

### 1. سیٹنگز میں "Shop Details"
- اب آپ سیٹنگز میں جا کر **Personal** اور **Shop Info** کو الگ الگ ٹیبز میں کنٹرول کر سکتے ہیں۔
- آپ اپنی دکان کا نام اور لوگو (Store Logo) اپنی مرضی سے سیٹ کر سکتے ہیں جو کہ آپ کے اصلی نام سے مختلف ہو سکتا ہے۔

### 2. بازار میں اسٹور کی پہچان
- بازار (Bazaar) میں اب خریداروں کو آپ کا اصلی نام نہیں، بلکہ آپ کی **دکان کا نام** نظر آئے گا۔
- اگر آپ نے دکان کا نام سیٹ نہیں کیا ہوگا، تو ایپ خود بخود آپ کا اصلی نام استعمال کرے گی (Fallback)۔

### 3. سیلر اسکرین کا نیا ڈیزائن
- آپ کی اپنی دکان (`SellerItemsScreen`) کے ہیڈر میں اب آپ کا اسٹور لوگو اور نام نمایاں طور پر نظر آئے گا۔
- یہاں بھی "تصدیق شدہ" (Verified) بیج اور "Trusted" ٹیگ موجود رہے گا۔

## کیسے استعمال کریں؟
1.  **Settings** اسکرین پر جائیں۔
2.  **Update Profile** (پنسل آئیکن) پر کلک کریں۔
3.  وہاں **Shop Info** والے ٹیب میں جا کر اپنی دکان کا نام اور تصویر اپ لوڈ کریں۔
4.  محفوظ کرنے کے بعد **Marketplace** میں جا کر دیکھیں، وہاں آپ کی نئی شناخت نظر آئے گی۔

> [!TIP]
> آپ کا ذاتی کھاتہ (Ledger) اب بھی آپ کے اصلی نام سے چلے گا تاکہ سپلائرز اور دوستوں کے ساتھ لین دین میں کوئی ابہام نہ ہو۔
