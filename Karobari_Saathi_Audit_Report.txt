کیا حساب کتاب درست ہے؟

فارمولا کی سطح پر ہاں:
- جمع = type == 'income' → accountBalanceAmount
- بنام = type == 'expense' → accountBalanceAmount
- Balance = opening + جمع − بنام   (account_service.dart:97)
- Profession: netProfit = totalIncome − totalExpense
- Discount: % → subtotal * p / 100 clamp؛ Rs clamp to subtotal؛ net = subtotal − discount
- Quick Bill fully paid: balance contribution 0 (tested)
- Stock qty signs درست
- /0 profession getters میں handle

ڈومین/UI کی سطح پر نہیں — تین بڑے سوراخ:

1) فروخت vs رقم لی ایک ہی income
   دستی کھاتہ: "رقم لی / جمع" = پیسے وصول
   فوری بل فروخت بھی income
   ادھار سامان جمع بن جاتا ہے، لیبل "دینا ہے"
   روایتی کھاتہ: سامان دیا = بنام / لینا ہے

2) حساب برابر ≠ کھاتہ باقی
   Cycle txs کو صفر پر reset کرتا ہے، opening نہیں جوڑتا
   Header صرف موجودہ cycle کی جمع/بنام
   Dashboard کل party.balance
   ایک پارٹی پر دو مختلف باقی

3) فی ایکڑ / فی من
   رقبہ 0 → تقسیم 1 سے
   پیداوار productionMun save، costPerUnit totalProduction پڑھتا ہے → 0
   کرایہ rentPerAcre * area report میں ہے مگر profit میں الگ expense نہیں
   (اگر کرایہ tx نہ لکھی ہو تو منافع زیادہ)

Rounding:
- UI اکثر روپے toStringAsFixed(0) — Rs 10.6 → 11 display، storage double
- Cycle 0.01
- بڑی رقم (10 لاکھ+) double OK (~15 digits)
